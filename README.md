# CalcMaster Web - 通用计算器 Pro

一款支持平板和手机的通用计算器 Web 应用。

## 📱 功能特点

- **普通计算** - 基本四则运算
- **科学计算** - 三角函数、对数、阶乘等
- **金融计算** - 单利、复利、月供计算
- **历史记录** - 自动保存计算历史
- **响应式设计** - 完美适配 iPad / iPhone

## 🌐 在线演示

- **手机版**: https://13888285815.github.io/CalcMaster-web/CalcMaster.html
- **平板版**: https://13888285815.github.io/CalcMaster-web/CalcMaster-iPad.html

## 🚀 技术栈

- HTML5 + CSS3 + JavaScript
- 纯前端，无需后端
- 支持 PWA 可添加到主屏幕

## 📦 使用方式

直接在浏览器中打开 HTML 文件即可使用。
